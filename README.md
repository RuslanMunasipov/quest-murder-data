# Quest Murder data

Game data for the Quest Murder plugin (WoW Forever), published as release assets. No plugin code lives here.

Each release holds the quest, NPC, object and item tables built from the Forever store of
[QuestieDB](https://github.com/Questie/QuestieDB) (GPL-3.0), plus `manifest.txt` (QuestieDB version, file sizes and
SHA-256 sums). Releases are made automatically when QuestieDB publishes a new Forever build.

The data is derived from QuestieDB and keeps its license: GPL-3.0.
